Ayuda de conexión

Para conectar tu dispositivo Heltec, seguí estos pasos:

  1. Abrí Chromium y escribí chrome://flags en la barra de direcciones.
  2. Buscá Experimental Web Platform features. Activala solo si tu aplicación necesita esa función.
  3. Si tu versión incluye una opción experimental para los permisos de Web Bluetooth y realmente la necesitás, consultá su documentación antes de cambiarla.
  4. Si modificaste alguna opción, presioná Relaunch para reiniciar Chromium.
  5. Volvé a LoRa Chat, pulsá Conectar y elegí tu dispositivo Heltec cuando aparezca la ventana del navegador.

Importante: la web debe ejecutarse desde HTTPS o localhost en un navegador compatible con Web Bluetooth. La página no puede cambiar automáticamente las opciones de chrome://flags ni concederse permisos de Bluetooth.
